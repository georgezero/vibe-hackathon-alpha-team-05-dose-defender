# Known Limitations — Dose Defenders

## Current

Only 5 wave types implemented. Pathfinding is fixed-route, not dynamic.

## Planned but not implemented

- Mobile touch controls
- Sound effects and music
- Persistent leaderboard (currently localStorage only)
- Difficulty settings menu
- Additional levels/modes
- Accessibility features (keyboard navigation, screen reader support)

## Won't fix (out of scope for hackathon)

- Multiplayer networking
- Backend data persistence
- User accounts
